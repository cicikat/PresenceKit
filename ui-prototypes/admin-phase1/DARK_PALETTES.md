# 深色配色对照

打开 `refined.html`，顶部“深色配色”选择后自动进入夜间。日间配色不变，输入和折叠状态保留。

| 方案 | 背景与卡片 | 紫色与其他颜色的分工 |
| --- | --- | --- |
| 石墨紫（默认） | 中性石墨底、灰色卡片 | 灰紫标题区、浅紫主按钮、冷灰侧栏，最克制 |
| 靛蓝紫 | 海军蓝底、蓝灰卡片 | 靛紫标题区、薰衣草按钮、青色成功提示，偏专业 |
| 暖梅紫 | 暖炭底、暖灰卡片 | 梅紫标题区、浅丁香按钮、米灰侧栏，偏温润 |
| 矿石紫 | 深青底、青灰卡片 | 紫灰标题区、浅紫按钮、蓝灰侧栏，分区最鲜明 |
| 原版深灰 | 原先 A 的深灰配色 | 保留原方案供对照 |

各方案单独定义页面、卡片、输入、标题区、结果表头、侧栏和边框；紫色集中在标题区、主操作和焦点。成功使用绿或青色，错误使用珊瑚色，不依赖颜色单独表达状态。

已通过脚本语法检查、DOM 替身中的五种配色切换与状态保留、日间恢复、LF 与差异检查。四套新增配色的正文和说明文字在页面、卡片、输入、标题区、侧栏、结果表头底色上，及主按钮文字的计算对比度均达到 4.5:1。

浏览器真实渲染仍未实测，沿用此前 file URL 工具限制。只修改独立样机，不接入生产。
