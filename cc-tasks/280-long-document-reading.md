# 280 长文档全文回读、结构、概要与跨轮进度

用户授权：修复万字以上上传文档截断、无法看全、读后失去上下文；区分 TXT/MD/Word。

根因：QQ 与 HTTP 上传各只注入前 3000 字且无稳定文档引用；read_document 返回 2000 字正文加头部后被统一 2000 字裁剪，next_offset 却按原分页前进；摘要只是首部摘录。资料已读回执只表示摘要已提供，不表示正文看全。DOCX 仅解析段落，遗漏表格。

- [x] 统一上传正文投影：完整解析保存到当前 uid/char 资料库，初始摘录明确范围、总长度、稳定 ID 和续读方法；资料库失败明确不能回读，不伪报存储成功。
- [x] read_document 提供 context/overview/summary/continue：每页至多 6000 字、连续偏移、总字数、章节/起始行、目录分页、提供范围与下一未提供位置；工具专属有界结果不再二次截正文。
- [x] 新上传保留结构与解析类型；DOCX 段落/表格按顺序抽取；TXT 支持 UTF-8 BOM、UTF-16 BOM、GBK，MD 保留标题；不把 Word 页码当可准确推导信息，不伪称支持旧 DOC。
- [x] 资料库持久化全文分块概要和已提供范围；摘要走冻结角色的 summary preset，分块后合并，失败保留 pending/partial 并可重试，发送后后台调度，显式请求 summary 可按需生成。
- [x] 同作用域锁和修订校验防止摘要任务复活已撤回文件；跨轮只投影有界概要/进度，不进入长期记忆。复用资料库只读观测，暴露摘要/进度状态而不泄露正文。
- [x] 接线 QQ、desktop/mobile 共用上传与工具链；补关键回归：万字尾段、无漏字分页、DOCX 表格、摘要重试/重开/撤回、作用域及 portable schema。
- [x] 文档、差异与换行检查，独立提交。

验收边界：支持单文件 5 MiB、解析文本最多 500000 字符，超过文本上限明确拒绝而非静默截断。一次模型上下文无法承载任意大文档；提供可续读和分块概要，不承诺任意长度一轮完成。提供进度仅证明工具结果已返回，不等于模型理解。新正文可持久回读，历史上传若原本已缺失内容不能凭空恢复。无新增运营开关；复用既有 summary 路由和资料库管理观测。

删除 brief 候选：替换两处 3000 字无标记截断及误称“摘要”的首部摘录文案；随实现更新相关守卫。本单不清理历史资料、缓存、用户文档或跨仓无关代码。

验证：Python3.12，相关上传/QQ回复/媒体/资料库/文档/portable schema/角色名/作用域/LF 回归108 passed；资料接续相关另10项通过，3项屏幕文案旧断言失败，用未修改HEAD模块复现同样失败，不扩大维修。新增搜索回归保证8个资料ID和图片sha256不被裁剪。后台合成48k正文跨两个批次完成5段概要；真实小模型、三端实机和生产重启仍 observe。客户端只同步接口文档，保留其已有未跟踪临时目录。
