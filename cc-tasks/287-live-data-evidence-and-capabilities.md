# 工单 287：新鲜心率、溯源入口与实际能力提示

## 设计

只展示真实、授权、当前可用的数据与能力。提示词不授予权限；冻结/不可变更的开关不作为可开启能力。
有确切ID时给ID与对应查询方式；没有血缘时明确不能精确溯源，不伪造ID。
MCP 不常驻具体服务目录；self 可维护能力/用法/结果笔记，使用前重查当前连接和权限。

## A 新鲜心率

- [x] HDS owner、启用、角色读取许可全部通过时，只注入接收龄0..30秒的心率。
- [x] 无样本、过期、未来时间、关闭/非owner均零注入；不走旧watch事件，不触发分析或写入。
- [x] 纳入真实数据区块；已有HDS控制面与状态观测复用；31项回归通过，文档与独立commit。

## B 可查询的来源锚点

- [x] 审计 event_search/episodic/mid_term 及其他已带证据ID的资料，接到真实存在的工具参数。
- [x] 各条有界显示稳定锚点，保留时间、来源和派生边界；按需查原文，避免重搜全文。
- [x] 缺ID不能伪造；相关既有回归/新增最小测试、文档与独立commit。

## C 动态能力与self笔记

- [ ] 从最终实际工具暴露面介绍能做的事，不从全注册表宣称可用；不展示冻结能力为可开关。
- [ ] 明确可自主管理的功能ID、状态和边界；CAS/action_id及有效状态仍以执行合同为准。
- [ ] 有self工具时提示可以维护MCP能力笔记/表格，按需记真实用途与结果，不硬编码服务清单。
- [ ] 相关回归、文档、差异/LF检查与独立commit；实际模型/设备验收另记。

## 范围与删除候选

仅后端prompt与实际消费链；不改桌面/手机协议。无新增运营开关、持久账本或静态资源。
删除候选：动态能力说明落地后审计重复或固定工具名单提示；不删除独立安全/发现协议约束。
