# 271 消息分发与客户端设置

## 范围与验收
- [ ] 功能开关总览下方新增独立页面；顶端快捷开关，下方每客户端一个折叠卡片。
- [ ] 集中 QQ、微信、桌面、手机的连接配置与手机唤醒中继；旧入口指向新页。
- [ ] 桌面/手机总开关有真实 HTTP、WS、广播及 durable mirror 消费，默认兼容旧行为；关闭不删除队列。
- [ ] 地址及端口可配置，显示生效方式；协议兼容与本机部署目录职责有可移植说明。
- [ ] 相关回归、差异/换行检查、静态资源版本更新及隔离浏览器验收。
- [ ] 独立提交；不混入现有微信迁移修改。

## 边界
不安装或迁移现有服务，不修改真实凭据、生产配置和客户端仓库。协议自动探测/任意设备兼容需要独立适配器，不能冒充已经实现。

## 删除候选
旧页重复桥配置表单随本单迁移；遗留游戏 sidecar 或服务目录不在本单清理授权内。
