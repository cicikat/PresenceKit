# 313 后续独立工单（未实施）

本文件分配 313-D / 313-E / 313-F 子单，不占用其他工单编号。均为后续范围；313 B/C 的交付限制见 `docs/agent-capabilities-313-delivery.md`。

## 313-D0：明确目标与无改动证明（P0 遗留，未完成）

复用现有 task/work-session/grant/journal，冻结必要目标清单与每目标证据，避免一个目标保存即被当作全部完成。设计 already_satisfied/no_change_needed 的可验证、不可冒充编辑语义；明确要求发生编辑时不得以无改动替代。此项来自原工单 P0 验收，不能因拆单降为 P1，也不以当前 B/C 实现宣称完成。

验收：复合目标任一必要步骤未完成不得整体成功；已满足目标时报告无改动，必须写入的目标保持未完成；证据过期或撤权不得沿用。

## 313-D：文件成组变更（P1）

前置：D0 目标合同与313 B/C 真实 Windows 临时授权目录联调通过。按独立能力实现 mkdir、rename/move、copy、可逆 remove 和多文件 patch；预览、hash、部分成功及恢复步骤必须可查询。大文件/二进制解析使用明确格式路由。

验收：多目标之一失败不得整体成功；重复 ACK、不确定写入、撤权、冲突和撤销走真实入口；仅使用合成临时文件。删除候选：新原语完整承接后移除旧 find 混合名称/正文扫描及其专属测试与文档。本轮不执行删除。

## 313-E：Windows 受限进程与浏览器工作流可行性 POC（P1）

前置：先盘点现有 process_run、Agent task、MCP、browser_automation、Computer Use 的真实部署及授权。POC 仅运行预先批准的临时项目测试命令，复用统一任务系统；冻结 owner/char/workspace/设备绑定，限制程序/参数/路径/网络、时长、CPU/内存/输出，取消时清理进程树。返回退出码、有限 stdout/stderr、产物和来源。禁止默认为无限制远程 shell。

浏览器 POC 区分搜索、文本获取、DOM 交互、下载和 GUI；核实浏览器所在设备与登录态，单独设计 DDGS 失败时的 provider fallback。交付安全边界方案、最小 POC 和真实临时目录/公开网页回执后，再决定正式协议实施。

## 313-F0：扫描中撤权与取消（P0 遗留，未完成）

桌面扫描须支持逐条合作式取消及 grant/epoch/revision 重查，避免当前共享锁导致撤权等待最长有界扫描。保持后端取消后不暴露结果。通过真实并发扫描/撤权测试证明及时停止；目前的一秒扫描上限不能代替这一验收。

## 313-F：观测与聊天体验验收（P2）

增加脱敏聚合成功率、规划错误率、真实设备执行次数与 P50/P95，复用只读观测。

聊天展示自然的发现/读取/保存进度、相对位置、截断标记和失败原因；同名目标请求选择，不猜测。通过真实 Windows Tauri 临时目录验证名称搜索、分页及一次编辑 hash 回读；另验旧桌面拒绝、新旧部署/回滚、断网重连、授权撤回。macOS 单列验收，Android 只检查实际消费链。无实机证据时保留 pending physical verification。
