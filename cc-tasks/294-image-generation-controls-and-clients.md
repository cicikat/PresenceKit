用户授权跨仓施工。顺序：后端契约与管理面 → 两端消费 → 联合验证；不改生产密钥和私有角色数据。

- [x] 后端：生图预设校验、显式默认预设、模型发现、真实生成连通性测试（不写聊天/角色记忆），覆盖鉴权、错误脱敏与配置热重载。

- [x] 桌面依赖：图片 metadata → 有鉴权 IPC → 缩略图/放大/下载；手机依赖：同契约 → 图片/放大/二进制保存。
- [x] 相关测试、三仓接口/控制面文档同步，独立提交。
- [ ] 外部真实图像服务及实际设备验收（无资源时明确 not-run）。
