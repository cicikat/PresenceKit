# 工单 266：角色主动发起视频电话

## 合同

角色可在普通对话工具循环或主动评估中调用 `invite_video_call`。仅向当前固定角色所属的已连接桌面端发起一次来电，10 秒内等待主人选择。独立来电窗口置顶显示“接通/拒绝”；超时为 `unanswered`，拒绝为 `declined`，两者作为工具结果返回角色。接通为 `accepted`，桌面进入现有视频通话页；不自动开启摄像头或麦克风。主人在通话页主动挂断后，后端接收 `owner_hung_up` 事实并给同一角色一次有界的主动行动/说话机会。设备断线、重复请求、错误角色、迟到回执均不得打开旧来电。

## 施工

- [ ] A. 后端邀请状态机、10 秒期限、结果回传与只读观测；验证单次终态、角色/设备绑定和断线。
- [ ] B. `invite_video_call` 注册、普通对话及 autonomy 可用性、结果语义；验证权限、预算与回合续接。
- [ ] C. 桌面独立置顶来电窗口，接通/拒绝、倒计时与超时关闭；接通打开现有视频页。
- [ ] D. 主人挂断回传及一次性主动信号；验证只在真实接通后触发，不补发旧通话。
- [ ] E. 三仓接口、工具和控制面文档；相关测试、构建、差异检查、真实 Windows 窗口验收记录。每项通过后独立提交。

## 验证边界

单测、构建不代替真实 Windows 置顶窗口、焦点、摄像头和麦克风验收。手机本工单不消费邀请，不改手机仓库。保留其他人的未提交改动。
