# 262 — 角色日记限时补写

确认范围：角色自己的日记；本地时间当天 23:00 起可补当天，次日全天可补昨天。
只允许这两个日期；已有文件（包括空文件）不覆盖。未提供日期时，23 点前默认昨天，23 点起默认今天。

- [x] 注册 `backfill_diary`，沿用工具开关、角色授权和固定会话 scope；仅 owner 私聊调用。
- [x] 复用 authored_diary Work Session 和事实/感受生成，严格按目标自然日读取记录；无记录不编造。
- [x] 自动任务与工具共享生成锁，落盘原子发布且不覆盖；失败可重新请求。
- [x] 补充时间边界、重复/并发、失败重试、日期隔离与 dispatcher 回归。
- [x] 同步工具、调度与控制面说明，核对差异和换行，独立提交本工单。
