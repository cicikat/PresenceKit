# 288：角色工具权限、冻结功能入口、数据隔离与首次使用兜底

## 目标与合同

按维护者要求，删除 safe/danger 模式及工具风险说明、二次确认；角色默认拥有工具执行权限，用户仍可手动关闭全局或角色权限。首次配置与连接检查说明默认全开和权限调整入口。鉴权、调用来源、参数校验、实际设备连接、owner 身份和角色数据隔离仍是执行合同。

冻结/实验性设置移入「排错与管理 → 冻结or实验性功能」，正常设置不重复呈现；移动入口不自动启用冻结实现。

角色自己的记忆、用户认识、备忘录、trait、档案及 prompt 私有素材按角色隔离。审计物理路径、数据库行、缓存键、调用参数、管理 API 和 prompt 消费链，不能仅凭路径登记认定完成。共享服务凭据和基础设施不属于角色记忆；共享历史证据不得无依据复制给所有角色。

旧私有数据保留原件，归属明确才迁移；不因切换当前角色重新认领历史资料。新角色没有素材时返回空或中性状态，不能读取另一角色的私有配置。缺少可选能力不应破坏主聊天；必需服务配置失败应给出准确原因，不伪造成功。
