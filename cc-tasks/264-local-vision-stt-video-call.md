## 现状与边界

- 图像连接名是内部路由键（字母开头，后续字母/数字/`_`/`-`，最多 64 字符）；模型 ID 是独立字段。`huihui_ai/qwen2.5-vl-abliterated:7b-instruct-q4_K_M` 可作为模型 ID，不可直接作为连接名。当前管理面没有在提交前解释这一区别。
- 当前配置没有 `stt_presets`，`/transcribe` 走旧本地 Whisper；当前项目虚拟环境没有 `faster_whisper` 或 `whisper`，因此会报 422。单条 HTTP 访问日志本身不能证明是哪一种 422，需用响应正文复核。
- 桌面视频电话已有角色舞台、文字对话和按键录音；现实摄像头按钮仍禁用。音调感知只在配置了 STT 与声学分析后有可用来源，且应保持不确定性。
- 仅修改后端和桌面仓库。其他仓库无需改动。保留已有无关未提交文件和删除项。

## 设计约束

- 摄像头原始帧只在通话期间使用；未经明确保存动作不进入长期记忆或录像文件。视觉失败不阻断文字/语音聊天。
- 本地视觉只接受 loopback 服务和已配置的视觉连接；拒绝远端或 OCR 连接。推理期间只保留最新帧，过时帧丢弃；不能承诺零延时，以实际模型耗时为准。
- STT、视觉和 TTS 的本地计算避免同时压满设备；角色回复依然经现有会话身份、turn sink 和 TTS 开关。文字缓冲有长度与时效上限，失败时保留可编辑文字。
- 控制面显示 desired/effective 与阻断原因；持久排障状态有只读观测。变更实际接口时同步三仓接口总账与受影响端文档。
