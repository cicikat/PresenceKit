运行配置

这里编辑状态页摘要中的运行时控制项；每项显示配置来源和生效方式，状态页只保留只读摘要。

快捷操作

热重载会重新读取当前配置文件；需要重启的项目不会被错误地标记为立即生效。

Memory Event shadow rollout

Only compares old and event-ledger recall. Results are excluded from the production prompt.

effective: -apply: -

状态权威与记忆解释开关

以下开关均热生效，保存后下一轮对话起生效；默认值即现状，关闭或恢复默认即回到现状。

effective: -apply: -

StatePacket 影子记录（观察用）

默认关闭。只记录每轮各提示层的来源与权威级别，不改变提示词；可只对名单内的用户或角色灰度开启。关闭即回到现状。

Dossier 记忆档案

注入档案：默认开启；关闭后档案不进提示词，也不再压制旧召回（工具与夜间整理不受影响）。压制范围：默认“全局”（有档案就清掉旧召回文本，现状）；“按证据重叠”只去掉与档案证据重合的条目。

隐性状态置信度门控

默认关闭。开启后，置信度不足的隐性状态字段不参与需求评分、写信原因与梦境快照。注意：置信度是“对该状态估计的可信度”，不是状态本身的强度。关闭即回到现状（仅在观测中记录原始值与门控值）。

高级设置

语义召回最低相似度：只对没有关键词命中的纯语义候选生效，0 表示不过滤（默认，现状）。建议先看召回观测里的相似度分布再调高。

EventContext observer

Records redacted propagation metadata only. It never changes the production write path.

effective: -state: -
