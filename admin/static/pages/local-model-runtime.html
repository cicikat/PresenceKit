本地语音识别

只管本机运行的语音识别引擎（faster-whisper 或 sherpa-onnx）。远程 OpenAI 兼容语音识别连接在「语音合成与声音（TTS、STT）」页配置，两处不重叠。保存时先热切换，成功后才写入配置；失败会保留原来能用的设置。

本机硬件检测

beam_size 越大越准但越慢；延迟要紧时可调小。第一次换更大的模型可能要联网下载权重，保存会等到加载完成，可能需要几分钟。

sherpa-onnx 模型文件

sherpa-onnx 只做整段离线转写，不是边说边出字。它会按停顿切句、用束搜索解码，并折叠异常连续重复；专有名词词表会作为热词偏置（只在束搜索下生效）。选了它而加载失败时不会偷偷换回 Whisper，会明确报错。
