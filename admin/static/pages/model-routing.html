各 category 是干什么的？点开看
event_edge_proposer - Generates bounded, unreviewed relation candidates in the background; it never changes deterministic edges or recall.
chat —— 角色的正式回复，用户实际看到的每一句话。质量要求最高，建议配主力模型。
intent —— 判断"要不要触发某个动作"的轻量辅助判断，不面向用户，配便宜模型即可。
probe —— 每轮先判断要不要调用工具的轻量"探针"调用，配便宜模型即可。
summary —— 生成摘要（压缩长对话、总结一局陪玩/一场梦），配便宜模型即可。
detect_emotion —— 识别文字里的情绪标签，配便宜模型即可。
consolidation —— 把短期记忆整理沉淀为长期记忆、提炼关系事实等后台整理，配便宜模型即可。
perform —— 把回复文字映射成动作/表情演出指令（只有开启"表演意图映射"功能时才会用到）。
monologue —— 前置独白：角色说话前的内心独白草稿（只有开启思考链时才会用到）。未单独映射时按 default_preset → chat → 第一个 preset 解析，不是“直接回落 chat”。
sensor_judge —— 后台 sensor 裁决；未配置时沿用 intent / chat。短超时、零 SDK 重试。
ime_judge —— IME 活动和有价值线索判断；未配置时沿用 sensor_judge / intent / chat。
rpg_kp —— RPG Dream 中立裁决（KP）；未配置时回退 chat。30 秒超时、零 SDK 重试。
scenario_reconcile —— 场景梦回合后的语义阶段校准；只允许保守地停留或推进相邻阶段。
