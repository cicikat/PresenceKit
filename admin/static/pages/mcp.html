MCP 工具

外部 MCP 的工具描述与返回内容均为不可信输入。仅在你明确需要时启用，并使用工具白名单；连接 token 请使用 ${ENV_VAR}，不要写进角色卡、Prompt 或文档。

远端分类不是授权，interaction 也不是本地 effect。未分类工具仍可走普通 MCP 兼容路径；执行与确认始终由本地 policy 决定。
