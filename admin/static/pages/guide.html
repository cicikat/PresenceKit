先看这里

点击侧边栏分类标题可收起或展开，点击下面的小入口直接进入页面。分类首页仍保留。展开状态会记住；跳转到某页时会展开它所在的分类。

我想做什么？

想换模型，或者只给某个角色换模型

先在「模型连接与分工」配置连接和方案，再到「角色的模型、声音与形象」选择角色专属方案。跟随全局的角色使用全局方案。

想调整回复风格、思考或分条发送

打开「聊天方式与思考」。如果是表情包或声音，分别进入回复表现与语音合成设置。

想调整主动消息，或排查为什么没提醒

先检查功能开关，再设置主动消息时段和策略；没触发时看主动活动记录与诊断。

想改人设、世界设定或启用素材

角色卡编辑人设；现实设定编写素材；启用角色与素材页决定当前使用哪一套。梦境使用独立设定。

回复不对、工具失败，想知道发生了什么

先看聊天记录和prompt检视；工具失败看执行记录，连接错误看服务调用与错误日志。

几个容易混淆的名字

模型连接 / 预设（Preset）
一份模型的服务地址、密钥、模型名等连接参数。
模型方案 / 路由（Profile）
决定不同任务使用哪个连接，比如聊天、总结分别交给不同模型。
角色绑定
某个角色的专属选择；跟随全局表示不另设覆盖。
已开启 / 已配置 / 实际可用
已开启是开关意愿，已配置是参数齐全，实际可用还取决于授权、连接、角色范围和运行条件。
观测 / 记录
查看发生了什么、为什么发生；要改行为应去对应设置页。含管理动作的页面会单独显示操作按钮。
后端设置与客户端偏好
模型、能力权限等由后端管理；桌面外观、播放偏好及本地确认留在客户端。手机也只使用它支持的能力。
