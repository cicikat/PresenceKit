# 中文句中单换行与显示段落

2026-10-26：只读核对用户报告对应的生成快照，确认词内单换行已在生成结果中；两个客户端按单换行拆泡，因而共同呈现碎片。不能从时间先后断言情绪改造导致模型换行，也不能将未部署的手机R2当作原因。

修复复用 `output.segment_enforce.enabled` 和现有 GET/PUT `/output-segment-enforce`（persona）控制面，默认关闭、热更新；关闭即发送清理后的模型原换行，无新参数、权限或状态。

开启时先保守合并中文字符之间的句中单换行；明确空行、句末、列表/引用/标题/表格、说话者标签、NMP块边界、代码围栏/缩进代码、Markdown两空格或反斜线硬换行保留。非中文软换行不猜测，也不改变标点、字词。随后仍按既有 min_len 规则在完整句末补空行。无法仅凭文本区分未标明的中文诗行与错误软换行；有意逐行排版应使用空行或Markdown硬换行，或关闭本开关。

桌面流式与最终正文共用状态机，最多保留不确定换行后的32字符来识别下一行结构，正常结束调用 finish。模型块边界不成为消息边界；CRLF跨块也一致。手机HTTP/poll/WS最终消息、桌面canonical与QQ发送副本消费同一清洗规则。无需新增前端切字器、字段、ACK或设置，Dream不在范围内。

原始生成、prompt观测和短期记忆保持原样；反坍缩仍观察原生成形状。此改动只修之后发送的展示副本，不批量回写旧聊天记录、既有展示投影或角色卡。历史旧坏换行不会因本地修复自动消失。

证据：新增回归先10失败，修复后69项通过；扩大输出/共享入口/手机/turn sink/WS/session与守卫回归187项通过。包含真实报告同条输出的只读本地重放：中文句中单换行5处降为0处，除空白外字符完全一致。私有原文、凭据和身份不写进工单或fixture；提交测试使用合成样本。
