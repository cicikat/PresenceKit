# 管理面板延迟优化（2026-11-15）

目标为交互响应 200ms；已完成本地优化、隔离验收与指定实例部署，不能宣称远程首开和所有操作均达标。

## 修改

- 文案默认值按原文建立索引，避免每个文字节点遍历全部文案；DOM observer 每帧只处理变化的子树，并在自身投影期间断开，避免重复触发。
- 未启用且没有保存编辑状态时，编辑器不再扫描所有页面。保存过的文案、排序和显式编辑模式继续应用。
- UI 装饰器按变化节点和所属卡片更新；加载片段只挂载该片段，不再刷新所有已访问页面或广播全局 UI 版本变化。
- 翻译结果未变化时保留文字节点；普通零滚动切页不再强制同步布局。
- 页面底部脚本用 defer 并行下载、按依赖顺序执行；主题首帧脚本保持原先执行时机。
- 中文衬线字体使用本机已安装字体及系统回退，不再自动下载 10,421,580 字节的完整中文字库；现有字体资产保留。不同系统字形可能略有差异。
- 配置读写优先使用 PyYAML 的 C 安全 codec，缺少扩展时回退 Python 安全 codec。原子写入、三方合并、写后校验和同步热重载保留；不缓存过期设置，不提前报告保存成功。

未新增设置、权限、协议或持久状态；桌面和手机没有管理面板渲染调用链，本次不修改客户端。共享配置加载器只更换安全 YAML 解析实现。

## 可复现验证

Python 3.12.13 / Windows / Chromium，全部使用合成配置、合成 API 和临时目录，未对生产配置执行保存。

```text
python tests/admin_performance_browser.py
python tests/admin_performance_browser.py --cpu-slowdown 4
python -m tests.admin_config_performance
python tests/run_admin_browser.py
python tests/admin_login_browser.py
python tests/admin_theme_boot_browser.py
```

Node 浏览器用例需要 Playwright 可由 NODE_PATH 解析；具体环境入口不写入仓库。

| 场景 | 测量结果 | 范围 |
|---|---|---|
| 累积 1500 张隐藏卡片后的输入到绘制 | 优化前约 68–82ms；优化后约 19–29ms | 浏览器真实资产、合成输入回显 |
| 实际导航点击到页面片段准备完成并绘制 | setup 94–117ms、runtime-config 33–43ms、guide 28–29ms | 默认新版；API 为隔离替身，不代表远程业务数据全部就绪 |
| 400 条合成配置的实际设置 POST | 原 codec 429–516ms；新 codec 83–111ms | 挂载实际 prompt-language router，含鉴权、落盘、校验、热重载，核对其他配置不丢失 |
| CPU 降速 4 倍的输入 | 旧资产约 511–1016ms；新资产约 22–37ms | 重放 HEAD 资产，旧实现触发 200ms 输入预算失败 |
| CPU 降速 4 倍的冷切页 | setup 约 253–497ms | **仍超出目标**；其他两页约 65–162ms |
| 冷启动全部脚本 DOMContentLoaded | 约 627–735ms | 隔离静态服务器，无线上压缩与真实网络；**未达 200ms**，不等同于首次绘制 |

浏览器回归覆盖导航、移动布局、滚动恢复、登录拒绝与成功、慢语言加载、草稿、配置 PUT、密钥清空、中英文保存按钮和主题首帧。新增性能脚本保留 200ms 输入和切页断言；CPU 降速参数用于额外压力测量，超预算会正常失败。

扩展 `admin_ui_business_browser.cjs` 的 `field/save button gap` 断言失败；使用未修改 HEAD 的静态资产重放也得到相同失败，属于既有按钮间距问题，本单不扩展修复。

定向配置/静态/语言/换行回归 30 passed、2 deselected（排除与本单无关的完整 prompt/tool 翻译检查）；扩展设置回归 93 passed、4 failed。四项失败都在 `test_settings_feature_flags.py`，测试将 `reload_config` 替换为空操作后，device-file 状态读取未初始化的全局配置，得到 `NoneType.get`；回退原 YAML codec 后该文件仍复现相同四项失败。未改动无关运行时或放宽断言。

## 指定实例部署与访问链路核验

用户提供实际回环管理隧道地址后，确认它转发到远端服务器，而非本机后端。服务器内部 HTML/脚本首字节约 3ms；本机隧道访问首字节约 0.88–1.54 秒，完整响应还包含传输时间。Tailscale 经东京 DERP 中继，三次往返为 312、330、304ms，未建立直连。这些数值已经超过单次操作 200ms 预算。

实际代理内核连接记录还确认发往该服务器的流量存在美国节点绕路。临时仅针对该服务器设置 TUN 直连排除后，公网 SSH 仍连接超时，已恢复原排除列表；没有留下代理规则或全局模式变更，没有开放公网管理面。

性能提交 `543ad28` 的 10 个程序文件已部署到指定实例。对入口页作定向合并，保留服务器页面品牌和历史记忆资源版本；合并后的导航、登录、配置 PUT、草稿、中英文回归通过。只保存本次覆盖的程序回滚副本，未执行私有数据备份或迁移。C 安全 YAML 扩展可用；重启后服务 active、NRestarts=0；私有配置哈希不变；原主版本标记保留，未把局部补丁标成整仓升级。

发布后发现入口页合并脚本误将注释里的旧缓存标记当成实际资源 URL，导致 core/i18n 两条 URL 漏改；已立即修正实际入口、部署 manifest 与回滚元数据，并重新核对全部 10 个文件哈希。实际地址的浏览器缓存重载确认 core/i18n/UI 均加载 `admin-latency-20261115`，未见脚本错误。

部署包、逐文件哈希及回滚入口保存在维护者的本地运维目录和服务器本次部署暂存目录，不记录凭据。

实际网络/隧道已确认超预算；所有页面的认证后数据就绪、真实配置修改及外部服务操作未作生产写入验收。验收浏览器的现有凭据不具备 admin scope，实际页面检查限于登录页和静态资源；配置写入证据仍来自隔离路由测试。不能把局部合成测量写成远程所有页面/按钮/保存均已低于 200ms。当前访问链路必须进一步缩短，才能达到端到端目标。
