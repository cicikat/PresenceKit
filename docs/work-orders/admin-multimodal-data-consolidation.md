## 边界与删除候选

聊天产物下载、媒体引用与日志的后端接口仍有客户端或工具消费者，本单只退役管理面入口，保留服务端功能和对应后端测试。IME 只合并接收模块，不把原观测总览的快捷入口当作数据配置。后端接口是否退役是后续单独审计候选，本次不执行。
