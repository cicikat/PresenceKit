# HDS 本地实时心率接入工单

## 范围与合同

- [x] 核对旧 `/watch/event` 捷径链、health_state 和 autonomy signal；HDS 使用独立入口，旧心率事件不作为新数据源。
- [x] 核对 HDS 本地协议：手表向电脑局域网地址的 HTTP 根路径发 `PUT`，外层 JSON 的 `data` 是序列化数据；接收端应兼容这一结构。
- [x] 提供可配置的独立局域网 HTTP 接收服务，默认关闭；入站连接不经过 HTTP 代理，限制报文和来源。
- [x] 将有效心率样本持久化，提供只读状态和近期样本查询，明确去重、过期与保留上限。
- [x] 在现有 scheduler tick 主动轮询本地样本，检测持续高位或相对基线变化，产生有界 autonomy 候选；HTTP 请求内不调用模型或发言。
- [x] 覆盖协议、去重、异常值、变化推断和来源限制；完成差异与换行检查。
- [x] 本工单独立提交；真实手表及局域网验收另行记录。

## 配置与验收边界

接收端口、允许的局域网来源及开关放在 `config.yaml` 的 `hds_local` 块；不把真实局域网地址写入版本控制。管理面只读观测近期状态。真实 Apple Watch 的传输频率、后台存活和 Windows 防火墙连通性，需要手表联机验收。

测试：`tests/test_hds_local.py` 3 项通过；扩展回归 34 项通过、2 项因并行运行进程修改生产 `data/` 文件，触发生产数据不变断言。未将这两项计作功能通过。未完成真实手表联机验收。
