验收：原表单节点只移动一次，切换布局可恢复；记录页面无修改入口；停用管理记录写入接口不影响角色写入。浏览器检查真实静态资源与导航；模拟接口不能证明生产连接或消息送达。

删除候选：本单授权删除管理面记录更正、重试、收藏编辑/删除入口及其专用代码与测试。调度器仍用于候选、维护任务和预算，不删除运行链。

证据：相关 Python 回归 60 项通过；Chromium 使用真实静态服务、清缓存后检查分组、嵌套、只读入口、客户端卡片和布局恢复，并检查截图。API 阻断，未验证生产连接或数据。旧吃食编辑浏览器用例随入口删除，替换为模块与只读验收。

既有失败：导航指南缺少 listening-player、memory-consolidation、minecraft 链接；其他页面包含内联样式。未改本单以外页面。
