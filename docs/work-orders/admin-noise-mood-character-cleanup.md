## C：情绪重设计（拟议，尚未施工）

决策：不再保存跨天的固定情绪枚举。人格、关系和事件记忆已提供连续性；情绪只保留有时效的短时余韵，不作为人格事实。

1. 当前表达：由角色本轮文本/动作及显式表演意图决定，沿现有 say segment/perform 出口发送。普通聊天与视频通话共用合同；缺少信号时不强填标签。
2. 短时余韵：记录来源回合、char_id、发生时间及过期时间；拟定最长 30 分钟，静默时自然淡出。角色可以改变或撤回，不需要同标签连续两轮。新回合不能被较晚完成的旧回合后处理覆盖。
3. 视频观察是用户可见姿态和表情的事实输入，不是角色自身情绪，更不写为用户内心事实。仅使用有效 TTL 的通话观察；角色结合上下文选择自己的回应。结束通话清除即时观察，不清除真实对话记忆。
4. prompt 只放低优先级、可裁剪的余韵软提示，含来源和新鲜度；没有有效信号就不注入。取消系统层的确定性“他此刻……”旁白，避免闭环自证。
5. 取消按钟点强制 sleepy、工具执行强制 thinking、关键词强制情绪。疲倦由角色当前表达决定；钟点仅保留现实时间背景。
6. 花园等 consumer 分别审计，不把短时表达写成持久人格，不用用户画面直接驱动角色花槽。

分单：C1 删除时间/工具强制写入及对应专用守卫、测试与文档；C2 统一即时表达与余韵出口，含乱序、TTL、reality/dream 隔离回归；C3 控制面与只读观测，显示来源、时间、过期及实际注入状态；C4 实际聊天和视频通话验收。涉及实际跨端字段变化时同步接口总账及消费端文档。每单验证后独立提交。

词语碎片另作可选创作轨：角色可留一句意象（如“杯底的小月亮”“电梯里的一场雨”），一天最多 12 条、有来源回合、允许不留；按需从当天素材拼一首散文诗，无素材不生成，不自动广播，不回流用户事实或情绪。创作不影响即时表情，不以额外模型调用阻塞回复。若做运营开关须配管理面热设置和观测。这不是 C1/C2 的必需依赖。
