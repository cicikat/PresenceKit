# 292-A/C：云端与用户设备能力核对

本表区分当前代码路径、实际部署证据和真实设备验收。remote_server 不会把服务器的 localhost 自动映射到用户电脑，也不会让停止的桌面进程自动运行。

## 可复用部署与恢复

`integrations/deployment/` 提供无凭据的systemd、桥接Compose及环境模板。Compose三种桥均需显式profile，不默认启动全部第三方服务；微信镜像需按[现有构建说明](wechat-reference-transport.md)在仓库外准备，不把上游源码或登录凭据提交。

后端仅监听回环；公网客户端与私有管理面分离见[入口合同](user-teach/public-client-private-admin.md)。管理可使用公网SSH隧道，不强制Tailscale。先验证新的管理账户、公钥与sudo，再收紧密码/root登录，保留原会话及带时限回滚；真实重启后复核SSH、TLS、scope、客户端角色/会话/历史及桥接登录，再撤销自动回滚。

更新前停止后端，运行backup-state create/verify，确保失败分支重新启动原服务；程序与数据分别保留回退点。解包源码只覆盖受控源文件，绝不能用公共config.example.yaml覆盖现用config.yaml、Token、模型连接或私有角色数据。生成并校验公网allowlist后reload Nginx，再验收两端启动接口和WS。
