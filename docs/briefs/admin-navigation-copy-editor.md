编辑方式：点击右下角编辑按钮，再点击文字修改。编辑期间文字点击优先进入编辑，结束编辑后恢复原交互。拖动侧边栏页面可调整顺序或所属分类。修改保存在当前站点的浏览器 localStorage，不修改配置或 API 数据；清除浏览器数据会丢失修改，应使用导出备份。动态状态文字也仅改变当前浏览器的显示，不改变实际运行状态。

退出阶段：用户完成修改后，先导出并审核文案与排序，将批准的修改写入正式源码，再移除编辑脚本与入口。本单不提前移除。

验证：既有浏览器回归通过，补充了实验功能三模块、称谓位置、文案编辑、跨分类拖动、导出和刷新持久化验证。Python 相关回归 20 项通过，另有两项既有静态缺口：指南尚缺 Minecraft、共同听歌播放器和角色记忆档案入口；删除相关页面已有内联样式。未扩大本单修复范围。

删除候选：用户管理页面退役后，可另单审计 status-users 中仅供该页面使用的 profile、黑名单和删除记忆 handlers；称谓和角色页仍使用的用户接口必须保留。本单未授权删除这些后端能力。
