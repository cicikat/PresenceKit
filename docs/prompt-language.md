# 框架提示词语言（291）

`prompt_language: zh|en` 是全局服务端设置，缺省/非法值回退 `zh`。管理面登录后读取服务端真值；语言菜单选择 English 时先保存 `en`，成功后才切换 UI。保存失败恢复原选项并显示错误；刷新或另一个浏览器登录时以服务器值为准。登录前仅切换浏览器显示，不写后端。

`GET /settings/prompt-language` 需要 `persona`，`POST` 需要 `admin`；写入使用现有配置原子写/合并入口并热重载。返回 `language`、`effective_language` 和 `default`，只接受 `zh`/`en`。运行中的请求不重译已经构造的消息，后续构造读取新设置。桌面/手机聊天也使用同一后端提示词语言，不增加客户端语言设置或推送字段。

## 翻译边界

仅在框架字面模板组装时选取 EN 版本，不对成品 prompt 全文替换，不调用模型翻译。角色卡、人设、世界/剧本正文、作者自写注记、AGENT.md、对话历史、用户上传、已保存的记忆和真实工具返回保留原文。English 不强制角色用英文回复，也不会翻译既有中文记忆。

当前接线包括 Reality 身份/来源区块/历史包装/输出与工具事实提示、分类发现与工具意愿、Dream 核心意识/导演/退出协议及剧本框架、主动循环内 QQ 空间与 IME 策略、工具近期/驻留投影、心声文风与独白框架、反坍缩提示。自主循环既有英文策略保持其原语义。

292 补齐陪玩状态/回忆、评论种子、观察标签、截图描述及收尾摘要的框架模板，以及视觉辅助模型的系统提示和背景包装、近期工具结果的失败/不完整提示。在实际组装点选择语言，游戏名、进度、观察、背景和历史摘要保持原文；已有陪玩日志不迁移。视觉 JSON 字段/枚举、敏感内容拒绝描述、摄像头本地路由及中文 caption 输出要求保持原合同。STT 实际请求只传用户配置的纯词表，不发送自然语言 `prompt()` 模板，因此保留词表原文，不新增语言开关。

`bundled/i18n/prompt-en.json` 保存框架字面翻译；`tools-en.json` 保存124个内置工具的原说明与 EN 配对；`schema-en.json` 保存204条参数说明。改工具原说明时，测试要求同步复核 EN；原说明不匹配不会冒用旧翻译。仅翻译说明字段，工具/参数名、enum/default、权限、scope、必填项、调用路由不变。动态第三方或角色自制定义不套用同名内置工具翻译；其原始数据和实际执行语义不改写。

## 验证

隔离 API 验证默认值、持久保存、非法值422、读写scope和其他配置保留；英文组装验证角色卡/世界/历史原文保留、工具schema结构不变、英文成功结果识别、梦境退出JSON协议及文风选择不变。默认中文既有回归同步执行。

浏览器使用真实静态资源和真实语言router的隔离服务验收，未启动QQ/微信/模型服务：English保存、切回中文、刷新持久化、模拟503时保留旧语言并显示错误均已实际操作。截图为本地ignored验收产物，不含生产凭据。真实模型对英文策略的行为遵从和所有功能组合的逐层prompt快照尚未实测，不以静态翻译数量替代模型验收。
